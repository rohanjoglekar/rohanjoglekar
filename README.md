## Engineering focus

| Evidence before promotion | Explicit execution authority | Production ownership |
|---|---|---|
| Measured costs, chronological holdouts, multiple-testing controls, live shadow evidence, and benchmark-relative evaluation. | Human arming, broker review, deterministic order identity, reconciliation, kill states, and read-only public surfaces. | Typed APIs and interfaces, service supervision, resource controls, monitoring, serialized deployments, backups, and incident-derived tests. |
